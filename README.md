# 托育适应期的过渡结果与继续预约

这里保存托育适应期的过渡结果与继续预约工作所用的匿名合成记录。文件不包含分析结果或居民个人资料。

## 资料

`samples/` 中每个文件都是独立的 UTF-8 JSON 文档：`children`、`timeline`、`calendar`、`capacity`、`staff`、`review`。日期是当地日历日期。空值表示没有对应观测或状态资料，不是数值零。

cohort 是首次接受日期；reported 为园方登记日。周几时段为园方营业标签，以 calendar 为准；capacity 列的是房间和教师同时满足时的每场容量。连续承接按四周核对，reserved 中实际确认按登记日起生效。

## 运行

使用 Python 3.11，无需第三方依赖或服务。`python3 inspect_samples.py` 逐个读取资料并列出记录数；`python3 -m unittest discover -s tests -v` 检查关键原始记录间的关系。输出只描述原始资料，不是业务比较结果。

## 过渡分析

`transition/` 包在原始资料之上实现试读到常规班的过渡分析，`run_analysis.py` 生成结构化 JSON 与可读文本报告：

```
python3 run_analysis.py [--openings 2] [--json-out 报告.json]
```

口径要点（与代码、测试一一对应）：

- **入口与分母**：以 children 的首次接受批次为入口，撤回、另选服务、原因未明、仍在等的孩子全部保留在批次分母中，不做幸存者筛选。
- **双口径**：每个截止日同时给登记口径（reported ≤ 截止日，工作人员当时所见）与修正口径（按 date 回看，纳入迟到登记）；迟到接收回执会纠正历史解释并按是否真的占班更新后续可约时段，已安顿家庭不重新争位（`planning.apply_late_receipt`）。
- **两套时间**：日历等待（自然日）与实际可用试读机会（calendar 开放且不在家庭暂停区间内）并列；园方停开（open=false）与家庭主动暂停分别计数、互不替代。
- **终态分类**：常规班实际接收、另选服务、家长撤回、原因未明、截止时仍在等五类；原因未明独立成类。申请转班不是终态，另次试读是独立后续段，不延长初次批次观察。
- **阶段比较**：仅比较相同观察阶段（7/14/21 天）；未在截止日前完整积累的批次标记 `observable=False`，观测数低于 `minimum_observations` 标记 `mature=False`；预约日结构是家长自选分层（`self_selected=True`），只作描述性并列。
- **容量与试算**：常规位与试读位分开；常规承接按连续四个开放日核对，全有或全无；同一教师跨房间冲突统一在台账中指出无法兑现的承诺。安排一（延长过渡）不新增常规承诺，安排二（开放少量常规预约）只对家长已同意时段给出可承诺候选，未同意时段仅作问询。

`python3 -m unittest discover -s tests -v` 同时运行原始资料测试（`test_samples.py`）与业务口径测试（`test_transition.py`）。
